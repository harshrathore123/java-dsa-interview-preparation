## ▶️ How to Run Java Programs

**1. Clone the repository**

```bash
git clone https://github.com/harshrathore123/java-dsa-interview-preparation.git
```

**2. Navigate to the project**

```bash
cd java-dsa-interview-preparation
```

**3. Compile a Java file**

```bash
javac ReverseNumber.java
```

**4. Run the program**

```bash
java ReverseNumber
```
